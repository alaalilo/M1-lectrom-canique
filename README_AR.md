# M1 Électromécanique — منصة مراجعة تعمل دون إنترنت

موقع ثابت (HTML + CSS + JavaScript بلا إطار عمل) يُنشر على **GitHub Pages**، ويُثبَّت كتطبيق (PWA) ويعمل دون إنترنت بعد الزيارة الأولى.

## البنية
- `index.html` — الصفحة؛ `assets/css/app.css` و`assets/js/app.js` — محرك التطبيق.
- `subjects-data.js` — بيانات المواد (قائمة الملفات وأي دروس/TD/TP/قوانين/QCM تضيفها).
- `assets/subjects/<المادة>/` — ملفات المواد (PDF وPPTX وDOCX وPython وCSV).
- `sw.js` و`manifest.webmanifest` و`offline.html` و`assets/icons/` — طبقة PWA.
- `downloads/M1S1_EM_Offline.zip` — حزمة كاملة مستقلة.

جميع المسارات **نسبية**، فيعمل الموقع داخل مسار مستودع مثل `/REPOSITORY/`. التنقل عبر `#/المادة/القسم` فلا يحتاج إلى خادم.

## النشر على GitHub Pages
1. أنشئ مستودعاً على GitHub وارفع **محتويات** هذا المجلد إلى جذره (يشمل `.nojekyll`).
2. من Settings ← Pages اختر Deploy from a branch ثم `main` و`/ (root)`.
3. افتح `https://USERNAME.github.io/REPOSITORY/` (يجب أن يكون HTTPS لتعمل ميزات PWA).

## العمل دون إنترنت
- **الزيارة الأولى تحتاج إنترنت** لتخزين الواجهة وبيانات المواد (Cache Storage عبر Service Worker).
- ملفات المواد **لا تُخزَّن تلقائياً** (حجمها كبير): اضغط «إتاحة دون إنترنت» على الملف المطلوب، ويمكنك حذف النسخة من الزر نفسه.
- عند فشل التحميل أو امتلاء المساحة تظهر رسالة على الملف فقط ولا تتعطل بقية المنصة.
- عند تغيّر الملفات يتغير رقم إصدار `sw.js` (VERSION)؛ فيُحذف كاش الواجهة القديم فقط، **دون المساس بتقدمك ولا بالملفات التي حفظتها**. أعد فتح التطبيق بعد ظهور تنبيه الإصدار الجديد.

## بياناتك الشخصية
تقدم المراجعة والمفضلة ونتائج QCM وآخر نشاط والوضع الليلي تُحفظ في `localStorage` بمفاتيح مستقلة لكل مادة (`m1s1-em:<subjectId>:...`). هي مرتبطة **بالمتصفح والجهاز الواحد**: لا توجد مزامنة بين الأجهزة، ومسح بيانات الموقع من المتصفح يحذفها.

## الخصوصية وحقوق النشر
كل ما يوجد في المستودع المنشور (بما فيه ملفات PDF) **متاح لأي شخص على الإنترنت**. لا تنشر إلا ملفات يحق لك نشرها، ولا تضع كلمات مرور أو بيانات شخصية.

## الحدود
- GitHub يرفض أي ملف أكبر من 100 MB، وينصح بمستودع أقل من 1 GB.
- مواد مثل «احترام المعايير وأخلاقيات المهنة» (≈ 180 MB من PDF) **غير مضمّنة** لتبقى الحزمة صغيرة؛ أضفها بنسخ ملفاتها إلى `assets/subjects/` وإضافة مادة في `subjects-data.js`.
- يتطلب تحميل الملفات دون إنترنت ملفاتٍ مخزّنة بنجاح؛ سعة التخزين تحددها المتصفحات.

## تشغيل النسخة المحلية (من ZIP)
فك الضغط ثم:
- **الأسهل:** افتح `index.html` مباشرة — تعمل الواجهة وفتح الملفات، لكن **لا تعمل ميزات PWA** (Service Worker وإتاحة الملفات دون إنترنت والتثبيت) لأنها تتطلب HTTPS أو localhost.
- **للميزات الكاملة محلياً:** شغّل في المجلد `python3 -m http.server 8000` ثم افتح `http://localhost:8000/`.

## إضافة محتوى
في `subjects-data.js` يقبل كل عنصر مادة المصفوفات: `lessons` و`td` و`tp` و`laws` و`quiz` و`mindMaps` و`nuances` و`gallery` بنفس بنية القالب السابق؛ وتظهر الأقسام التي تحتوي بيانات فقط. بعد التعديل **أعد توليد رقم VERSION** في `sw.js` (أي غيّره) لتصل التحديثات إلى المستخدمين.
